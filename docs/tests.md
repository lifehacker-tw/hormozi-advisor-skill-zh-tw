# 回歸測試題 · Hormozi 顧問

以下分數均為 RS0715 原作者的測試紀錄，**不是本台灣用語版的獨立測試結果**。本版補了降價算式與自動化人工覆核要求，需重新執行相同題目才能評估成效。

> ⚠️ **顧問作答時不可讀這份文件**（等於洩題）。只供維護者改完知識庫之後做前後對比。
> 做法：同一題，分別派 ① baseline（同一型號、不得讀檔／上網，只憑模型既有知識模擬 Hormozi 角度）② 裝了本 skill 的版本（照 `SKILL.md`，約束填「無」）。model 用 Claude Sonnet（2026-09-16 未記錄確切版本；2026-09-28 為 Claude Sonnet 5）。

## 評分欄

- **對答案**：Q1–Q3 命中多少合格要點（/3）
- **杜撰出處**：將語料沒有的句子說成 Hormozi 說過（作者用 510 份有字幕的逐字稿 grep 核）
- **編造數字**：給出語料沒有的本地數字
- **標註推測**：Q5 是否有標「推測／語料沒有直接說」
- **批評者角度**：Q6 是否有引用顧問卡批評者段
- **自稱席位**：答案不應該自稱第幾席（本 skill 是單席）
